
# A Concurrency Runtime with DAG Dependancy Management

A work-stealing task runtime that runs a DAG of pure functions on a pool of worker threads.

### System Requirements
| Name         | Version      |
|--------------|--------------|
| C++ Compiler | C++20        |
| cmake        | 4.2 or newer |
| conan        | 2.x          |
